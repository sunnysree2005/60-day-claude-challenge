# PDF Splitter & Merger

PDF Splitter & Merger is a premium, browser-based document utility developed as part of Day 39 of the 60-Day Claude Challenge. Designed for speed, privacy, and seamless document management, it allows users to process sensitive PDF files entirely client-side with zero server uploads and full offline capabilities after the initial page load.

The application features a robust PDF Splitter tool that automatically detects total page counts, renders high-resolution visual page thumbnails, and provides flexible extraction modes. Users can split documents using custom page ranges, interval splitting every N pages, specific cut-off points, or multi-range batch processing. It includes real-time validation to highlight invalid page entries and structural previews prior to file generation.

Additionally, the PDF Merger tool enables users to upload multiple PDF files via drag-and-drop or file selection, organize them in a sortable list with interactive reordering handles, and view vital metadata such as file counts, cumulative page counts, and estimated output size before generating the merged document.

Built using a single-file architecture combining semantic HTML5, modern CSS3, and modular vanilla JavaScript alongside robust client-side libraries like pdf-lib and PDF.js, the application delivers a commercial-grade aesthetic. It incorporates smooth transition animations, built-in dark mode support, high accessibility compliance, keyboard navigation, and responsive layouts optimized for any device. To get started, simply clone or download the repository and open `index.html` directly in any modern web browser. The project is distributed under the MIT License.
